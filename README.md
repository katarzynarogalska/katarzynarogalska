## [🛠️ AutoPrep](https://github.com/Pawlo77/AutoPrep/tree/main) - AutoML open-source Python package
AutoPrep is an open-source Python package published on [PyPI](https://pypi.org/project/auto-prep/) focused on automated machine learning with advanced data preprocessing techniques and model explainability methods. The key feature of this package is builing k independent pipelines with different sets of preprocessing methods, training models and choosing 3 best performing pipelines to generate a comprehensive report on the preprocessing methods used in the winner-pipelines.

Key features of the package are:
1. Automated data cleaning and preprocessing - Scaling, Encoding, Missing data imputation, Detecting highly correlated features, Detecting features with 0 variance and unique values
1. Intelligent feature type detection to assess the task type - binary/multiclass classification and regression
2. Feature selection and dimensionality reduction - PCA, UMAP, VIF, RF Feature importance, Correlation thresholds
3. Automated model training - KNN, Linear/Logistic Regression, SVM/SVR, Decision Tree, Random Forest, GBM, Bayesian Ridge
4. Hyperparameters tuning - Random Search with CV
5. Generating LaTex report with numerical scores, description of the preprocessing techniques, plots and SHAP interpretability metrics.


## [📊ARSA ML](https://github.com/katarzynarogalska/ARSA-Automated-Rashomon-Set-Analysis) - Rashomon Set analysis open-source Python package
ARSA ML is an open-source Python package developed to allow automated analysis of the Rashomon Set (a set of similarly well performing models, which despite achieving similarly high scores can have different charateristics) and the predictive multiplicity problem (a situation when multiple models produce conficting predictions for the same observations). The package is pubslished on [PyPI](https://pypi.org/project/arsa_ml/), along with a demo Streamlit application [ARSA ML Website](https://arsa-ml-website.streamlit.app/) allowing experimentation with the package features in a no-code manner. 
Key features of the package are:
1. Compatibility with [AutoGluon](https://auto.gluon.ai/stable/index.html) and [H2O AutoML](https://docs.h2o.ai/h2o/latest-stable/h2o-docs/automl.html) frameworks
2. Pipelines allowing automated construction of the Rashomon Set on user-provided dataset and trained models
3. Detailed Streamlit dashboard allowing analysis of the predictive multiplicity metrics and model characteristics
4. Rashomon Intersection - a novel approach proposing evaluation of similary-well performing models based on 2, instaed of just one, evaluation metrics

## [📈Reddit posts + Cryptocurrency market analysis](https://github.com/katarzynarogalska/Big-Data-Apache-project) - Big Data project using Apache 
This project was developed in order to determine a relationship between the spikes in negative, political Reddit posts and stability of the cryptocurrency market. In the project we used Apache Hadoop to store historical data, Apache NiFi to transform incoming stream data and Apache Spark and HBase to generate and save views with the processed analyses. 

Key features of this project are:
1. Apache NiFi - fetch streaming data from an API, select necessary features, use regex to determine policial posts and save data in Parquet format
2. Apache Hadoop - storing incoming large volumes of data in Parquet
3. Apache Spark - creating datasets and performing analyses, joining multiple datasets to obtain correlations and create final views
4. Apache HBase - storing views created with Apache Spark to enable random reads
